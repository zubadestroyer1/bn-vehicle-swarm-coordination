# Mathematical & Algorithmic Specification (`METHODS`)

This document specifies the mathematical formulation, network architecture, probabilistic inference rules, factored multi-intersection control algorithms, and statistical evaluation protocol implemented in `swarm/`. Every equation, tensor dimension, and hyperparameter below matches the executable Python source code in [`swarm/`](../swarm/).

---

## 1. Multi-Intersection Urban POMDP & Architectural Boundary Locks

### 1.1 Partially Observable Markov Decision Process Formulation

We formulate city-scale autonomous vehicle (AV) swarm coordination across an arbitrary directed urban road network $\mathcal{G}_{\text{road}} = (\mathcal{J}, \mathcal{C})$ of intersections $\mathcal{J}$ and merged approach corridors $\mathcal{C}$ as a discrete-time Partially Observable Markov Decision Process (POMDP) stepped at $\Delta t = 0.5\text{ s}$ (`2 Hz`):

- **Hidden Physical State ($s_t \in \mathcal{S}$)**: Evolved by Eclipse SUMO (`libsumo` / `traci`) microscopic physics using heterogeneous Intelligent Driver Model (`IDM`) longitudinal dynamics (`75%` `passenger_urban`, `15%` `passenger_cautious`, `10%` `delivery_van`), `LC2013` cooperative lane-changing, `3.0 s` yellow-clearance traffic light state machines, mid-episode arterial lane closures (`IncidentSpec`), and hidden per-vehicle origin-destination routes.
- **Observation Batch ($o_t \in \mathcal{O}$)**: Generated by [`ObservationChannel`](../swarm/env/observations.py) strictly from noisy range-limited roadside radar, entry/exit detectors, active lane-closure/TLS phase states, and budgeted delayed/dropped V2X query responses (`ObservationBatch`).
- **Filtered City Belief ($b_t \in \mathcal{B}$)**: Maintained recursively by [`CityBeliefTracker`](../swarm/env/belief.py) (`SwarmBeliefState`) without access to $s_t$.
- **Swarm Control Action ($a_t \in \mathcal{A}$)**: Emitted by [`FactoredSwarmCoordinator`](../swarm/control/coordinator.py) (`SwarmControlAction`), comprising:
  1. Conflict-free per-junction green TLS link sets $\mathcal{G}_J^t \subseteq \{0, \dots, L_J - 1\}$,
  2. Selective longitudinal speed advisories $v_{\text{cmd}, i}^t$ (with `-1.0` single-tick release to preserve `LC2013` lane-changing),
  3. Public observable edge travel-time costs $\hat{c}_e^{\text{DBN}}(t)$ for onboard hysteresis-guarded `sumolib` Dijkstra rerouting, and
  4. Budgeted Value-of-Information V2X poll requests $\mathcal{P}_t$ ($|\mathcal{P}_t| \le B_{\text{comm}} = 8$).

### 1.2 Three Enforced Architectural Boundary Locks

To eliminate subtle simulator leakage, fixed-degree intersection assumptions, and train/eval mismatch, the codebase enforces three hard invariants verified in [`tests/`](../tests/):

1. **Boundary Lock A — Degree-Agnostic Corridor & Exit-Fringe Topology** ([`swarm/contracts.py`](../swarm/contracts.py), [`swarm/dbn/features.py`](../swarm/dbn/features.py), [`swarm/control/maxsum.py`](../swarm/control/maxsum.py)):
   - Intersection approaches never assume 4-way cardinal geometry or fixed 3-turn vectors. Every corridor $c \in \mathcal{C}$ exposes an arbitrary-length tuple `turn_options` of $K_c = |\mathcal{T}_c|$ outgoing `TurnOption` branches, and vehicle turn beliefs lie on the exact probability simplex $\Delta^{K_c - 1}$.
   - Exit-fringe corridors (`is_exit_fringe = True`, $K_c = 0$) evaluate expected downstream occupancy and spillback identically to `0.0`; any non-exit corridor with $K_c = 0$ raises `TopologyIntegrityError`.
2. **Boundary Lock B — Hard-DAG `eval()` Validation Selection & Bounded L-BFGS-B Calibration** ([`swarm/dbn/calibration.py`](../swarm/dbn/calibration.py), [`swarm/pipelines/trainer.py`](../swarm/pipelines/trainer.py)):
   - During training, candidate parent edges use an annealed smooth relaxation ($\tau_{\text{dag}}: 1.0 \to 0.15$) so gradients flow into the precedence head.
   - Validation checkpoint selection and post-hoc temperature scaling $(T_{\text{edge}}, T_{\text{delay}}, T_{\text{link}}) \in [0.15, 10.0]^3$ are executed **strictly in `model.eval()` hard-DAG mode** on held-out `VAL_SEEDS = 2000..2009`, matching closed-loop inference identically. Uncalibrated or `ci_micro` checkpoints raise `CheckpointIntegrityError` if passed to the evaluator (`require_calibrated = True`).
3. **Boundary Lock C — Static AST Observation Firewall** ([`tests/test_train_eval.py`](../tests/test_train_eval.py), [`swarm/env/belief.py`](../swarm/env/belief.py)):
   - Static Python AST inspection verifies that **zero** runtime perception (`belief.py`, `observations.py`), DBN (`swarm/dbn/*`), or control (`swarm/control/*`) modules import `libsumo`, `traci`, `sumolib`, `VehicleRawTelemetry`, `GroundTruthStepRecord`, or `EpisodeMetrics`.
   - `DepartedVehicleEvent.entry_sim_time` must equal `obs_batch.sim_time` within $10^{-6}\text{ s}$ (raising `CausalityFirewallError` otherwise), preventing hidden SUMO `departDelay` insertion queues from leaking into `entered_at`.
   - Dynamic routing ([`swarm/control/routing.py`](../swarm/control/routing.py)) broadcasts public per-edge travel-time costs without reading any vehicle's hidden destination or `route_edges`.

## 2. Urban Road Topology & Partial-Observability Channel

### 2.1 Merged Corridor Topology (`RoadTopology`, [`swarm/env/corridors.py`](../swarm/env/corridors.py))

Urban SUMO networks (especially split arterial turn pockets in `grid3x3`, `grid4x4`, and OpenStreetMap `palo_alto_clean`) divide physical street blocks into consecutive internal segments. `load_or_build_topology` merges degree-2 non-signalized split segments into unified `CorridorSpec` objects characterized by total length $L_c$, speed limit $v_{\max, c}$, base lane count $\ell_{\text{base}, c}$, constituent `edges` with cumulative `edge_offsets_m`, and outgoing `TurnOption` branches. Under mid-episode lane closures (`open_lanes_by_edge`), effective corridor storage capacity updates dynamically (`jam_spacing_m = 7.0 m`):

$$
\ell_{\text{eff}}(c, t) = \min_{e \in \text{edges}(c)} \ell_{\text{open}}(e, t), \qquad C_{\text{eff}}(c, t) = \begin{cases} 0, & \ell_{\text{eff}}(c, t) \le 0, \\ \max\!\left(1, \left\lfloor \dfrac{L_c \cdot \ell_{\text{eff}}(c, t)}{7.0} \right\rfloor\right), & \ell_{\text{eff}}(c, t) \ge 1. \end{cases}
$$

Each `JunctionSpec` precomputes a symmetric boolean `turn_conflict_matrix` $\in \{0, 1\}^{M_J \times M_J}$ from SUMO internal connection foe geometry and a boolean `tls_link_foe_matrix` $\in \{0, 1\}^{L_J \times L_J}$ governing signalized link compatibility.

| Urban Network (`configs/networks/`) | Drivable Street Edges | Merged Corridors (Entry / Exit) | Total Junctions | Signalized TLS Intersections | 3D Extruded Buildings |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **`grid3x3`** (`grid3x3_nominal`, `rush_asymmetric`, `noisy_dropout`) | `84` | `48` (`12` / `12`) | `21` | `9` | `64` (procedural blocks) |
| **`grid4x4`** (`grid4x4_incident` — Zero-Shot OOD) | `144` | `80` (`16` / `16`) | `32` | `16` | `100` (procedural blocks) |
| **`palo_alto_clean`** (`osm_palo_alto_rush` — Zero-Shot OOD real OSM) | `361` | `275` (`23` / `25`) | `114` | `26` (`88` unsignalized) | `989` (OSM footprints) |

### 2.2 Range-Limited Noisy Radar & Delayed/Lossy V2X (`ObservationChannel`, [`swarm/env/observations.py`](../swarm/env/observations.py))

All observation noise and packet dropouts are generated via deterministic `np.random.SeedSequence([episode_seed, stream_id, step_idx, crc32(veh_id)])` so different policies evaluated on the same seed experience paired sensor realizations on identical vehicle states:

1. **Roadside Radar (`stream_id = 202`)**: Detects vehicles inside a junction box, within $R_{\text{radar}} = 95.0\text{ m}$ nominal (`85.0 m` in `grid3x3_noisy_dropout`) of the corridor stop-line, or within $\min(25.0\text{ m}, 0.5 R_{\text{radar}}) = 25.0\text{ m}$ of a non-entry corridor's upstream exit tail (monitoring spillback). Each in-range vehicle drops out independently with probability $p_{\text{drop}}$ (`0.10` nominal; `0.35` in `grid3x3_noisy_dropout`); surviving observations add Gaussian noise $\sigma_s$ (`1.2 m` nominal; `3.0 m` dropout), $\sigma_v$ (`0.45 m/s` nominal; `1.125 m/s` dropout), front-leader gap noise $\frac{\sqrt{2}}{2}\sigma_s$, and categorical turn-intent confusion (`0.78` base accuracy, `0.68` in dropout, boosted to $\min(0.94, \max(\text{acc}, 0.86))$ when physical turn blinkers are active).
2. **Budgeted Asynchronous V2X Queries (`stream_id = 303`)**: Accepts up to $B_{\text{comm}} = 8$ unique vehicle IDs per tick nominal (`B_comm = 6` in `grid3x3_noisy_dropout`) subject to a per-vehicle cooldown of $1.0\text{ s}$. Packets drop with probability $p_{\text{drop,v2x}}$ (`0.08` nominal; `0.40` in `grid3x3_noisy_dropout`); surviving packets incur discrete delivery latency $d \sim \mathrm{Uniform}\{1, \dots, d_{\max} + 1\}$ ticks ($d_{\max} = 2 \implies 0.5\text{–}1.5\text{ s}$ nominal; $d_{\max} = 3 \implies 0.5\text{–}2.0\text{ s}$ dropout) with tighter onboard telemetry noise ($\sigma_{s,\text{v2x}} = 0.30\text{ m}$, $\sigma_{v,\text{v2x}} = 0.12\text{ m/s}$, turn accuracy `0.97` nominal; `0.50 m`, `0.20 m/s`, turn accuracy `0.94`, and turn forgetting $\lambda_{\text{forget}} = 0.05$ in `grid3x3_noisy_dropout`).

## 3. City-Scale Filtered Belief Tracker (`CityBeliefTracker`, [`swarm/env/belief.py`](../swarm/env/belief.py))

### 3.1 2D Joseph-Form Kalman Filter with Anti-Creep Deadzone & OOSM Lag Inflation

For each active vehicle $i$, `CityBeliefTracker` maintains longitudinal corridor arc-length state $\hat{\mathbf{x}}_i = [\hat{s}_i, \hat{v}_i]^\top \in \mathbb{R}^2$ and covariance $\boldsymbol{\Sigma}_i \in \mathbb{S}_+^{2 \times 2}$ (initialized on entry at $v_0 = 0.85\,v_{\max, c}$, $\boldsymbol{\Sigma}_0 = \mathrm{diag}(4.0, 4.0)$).

**Prediction Step (`predict`)**: Consumes strictly post-safety commanded accelerations $a_{\text{post}, i}^{t-1}$ with a **stopped-queue deadzone** ($\hat{v}_i < 0.15\text{ m/s} \land a_{\text{post}, i} \le 0 \implies \hat{v}_i^- = 0, \hat{s}_i^- = \hat{s}_i$) that prevents clipped-Kalman forward position creep in red-light queues:

$$
\mathbf{F}_{\Delta t} = \begin{bmatrix} 1 & \Delta t \\ 0 & 1 \end{bmatrix}, \quad \mathbf{b}_{\Delta t} = \begin{bmatrix} \tfrac{1}{2}\Delta t^2 \\ \Delta t \end{bmatrix}, \quad \mathbf{Q}_{\Delta t} = q_v \mathbf{b}_{\Delta t}\mathbf{b}_{\Delta t}^\top + \begin{bmatrix} q_s \Delta t & 0 \\ 0 & 0.25\, q_v \Delta t \end{bmatrix}, \quad \boldsymbol{\Sigma}_i^- = \mathbf{F}_{\Delta t}\boldsymbol{\Sigma}_i\mathbf{F}_{\Delta t}^\top + \mathbf{Q}_{\Delta t},
$$

with nominal process variances $q_s = 0.6\text{ m}^2/\text{s}$ and $q_v = 1.1\text{ m}^2/\text{s}^3$ (`0.8` and `1.4` in `grid3x3_noisy_dropout`).

**Chronological OOSM Measurement Update (`observe`)**: Radar observations ($t_{\text{meas}} = t$) and delivered V2X packets ($t_{\text{meas}} = t_{\text{sent}} < t$) are sorted chronologically. Any out-of-sequence packet older than `last_meas_time` is discarded; valid delayed packets with lag $\tau = \max(0, t - t_{\text{meas}})$ are extrapolated forward to current filter clock $t$ ($\mathbf{z} = [\mathrm{clip}(s_{\text{obs}} + \max(0, v_{\text{obs}})\tau,\, 0, L_c),\, \max(0, v_{\text{obs}})]^\top$) with lag-inflated measurement noise:

$$
\mathbf{R}_{\text{eff}}(\tau) = \begin{bmatrix} 1 & \tau \\ 0 & 1 \end{bmatrix} \begin{bmatrix} \sigma_s^2 & 0 \\ 0 & \sigma_v^2 \end{bmatrix} \begin{bmatrix} 1 & 0 \\ \tau & 1 \end{bmatrix} + \begin{bmatrix} 0.25\, q_v \tau^4 + q_s \tau & 0.5\, q_v \tau^3 \\ 0.5\, q_v \tau^3 & q_v \tau^2 + q_v \tau \end{bmatrix}.
$$

With Kalman gain $\mathbf{K} = \boldsymbol{\Sigma}_i^- (\boldsymbol{\Sigma}_i^- + \mathbf{R}_{\text{eff}})^{-1}$, the covariance updates via the **exact Joseph form** to guarantee numerical symmetry and positive semi-definiteness (`require_psd_covariance`):

$$
\hat{\mathbf{x}}_i^+ = \hat{\mathbf{x}}_i^- + \mathbf{K}(\mathbf{z} - \hat{\mathbf{x}}_i^-), \qquad \boldsymbol{\Sigma}_i^+ = (\mathbf{I}_2 - \mathbf{K})\boldsymbol{\Sigma}_i^-(\mathbf{I}_2 - \mathbf{K})^\top + \mathbf{K}\mathbf{R}_{\text{eff}}\mathbf{K}^\top.
$$

### 3.2 Forgetting-Smoothed Categorical Turn-Intent Filter & Corridor Tail Blockage

For a corridor with $K_c \ge 2$ outgoing `TurnOption` branches and categorical sensor likelihood $\boldsymbol{\ell}_i \in \Delta^{K_c - 1}$, the turn-intent posterior updates with nominal forgetting rate $\lambda_{\text{forget}} = 0.04$ (`0.05` in `grid3x3_noisy_dropout`):

$$
\tilde{\boldsymbol{\pi}}_i = (1 - \lambda_{\text{forget}})\boldsymbol{\pi}_i^- + \frac{\lambda_{\text{forget}}}{K_c}\mathbf{1}_{K_c}, \qquad \boldsymbol{\pi}_i^+ = \frac{\tilde{\boldsymbol{\pi}}_i \odot \boldsymbol{\ell}_i}{\mathbf{1}_{K_c}^\top (\tilde{\boldsymbol{\pi}}_i \odot \boldsymbol{\ell}_i)}.
$$

Each vehicle's analytical two-regime free-flow stop-line ETA $\widehat{\mathrm{ETA}}_i$ (constant comfort acceleration $a_{\text{comf}} = 2.0\text{ m/s}^2$ up to $v_{\max, c}$, then cruise) is paired with delta-method uncertainty:

$$
\sigma_{\text{ETA}, i} = \sqrt{\frac{\Sigma_{i,00}}{v_{\text{eff}}^2} + \left(\frac{d_{\text{rem}, i}}{v_{\text{eff}}^2}\right)^2 \Sigma_{i,11} + (0.15\,\tau_{\text{age}, i})^2 + 10^{-4}}, \qquad v_{\text{eff}} = \max(\hat{v}_i, 2.5\text{ m/s}).
$$

Upstream exit-tail blockage per vehicle $b_{\text{tail}}(i) \in [0, 1]$ and noisy-OR corridor tail blockage probability $P_{\text{tail}}(c) \in [0, 1]$ (`CorridorBeliefStats`) are computed smoothly via the standard normal CDF $\Phi(\cdot)$:

$$
b_{\text{tail}}(i) = \Phi\!\left(\frac{22.0 - \hat{s}_i}{\sqrt{\Sigma_{i,00} + 1.0}}\right) \Phi\!\left(\frac{2.0 - \hat{v}_i}{\sqrt{\Sigma_{i,11} + 0.25}}\right), \qquad P_{\text{tail}}(c) = 1 - \prod_{i \in \mathcal{V}_c \setminus \mathcal{V}_{\text{junc}}} \bigl(1 - b_{\text{tail}}(i)\bigr).
$$

## 4. Heterogeneous Spatio-Temporal Graph Transformer DBN (`swarm/dbn/`)

### 4.1 Linear-Complexity $O(N_t)$ Topological Candidate Graph ([`swarm/dbn/candidates.py`](../swarm/dbn/candidates.py))

Rather than scoring all $N_t(N_t - 1)$ vehicle pairs, `build_candidate_graph` exploits corridor-sorted vehicle lists (`bisect`) to propose at most $K_{\text{cand}} = 20$ directed candidate parents $(j \to i)$ per destination vehicle $i$ across four physical `RelationType` classes:

| `RelationType` | ID | Quota | Topological & Kinematic Eligibility Window |
| :--- | :---: | :---: | :--- |
| **`SAME_CORRIDOR`** | `0` | $q_{\text{same}} = 4$ | Ahead on same corridor ($\Delta s_{ji} \in (-8.0\text{ m}, +85.0\text{ m}]$), ranked by same-lane then $|\Delta s_{ji}|$. |
| **`SAME_JUNCTION_CONFLICT`** | `1` | $q_{\text{junc}} = 8$ | Competing approach to same target junction, both $\widehat{\mathrm{ETA}} \le 12.0\text{ s}$, belief conflict/merge prob $p_{\text{conf}} + p_{\text{merge}} > 0.02$. |
| **`DOWNSTREAM_SPILLBACK`** | `2` | $q_{\text{spill}} = 4$ | Vehicle $j$ inside upstream tail ($\hat{s}_j \le 50.0\text{ m}$) of an outgoing corridor reachable by $i$ ($\pi_{i \to c_j} > 0.02$). |
| **`UPSTREAM_FEEDER`** | `3` | $q_{\text{feed}} = 4$ | Upstream vehicle $j$ ($\widehat{\mathrm{ETA}}_j \le 8.0\text{ s}$) turning into $i$'s corridor ($\pi_{j \to c_i} > 0.05$) while $\hat{s}_i \le 60.0\text{ m}$. |

### 4.2 Schema-Locked Heterogeneous Feature Tensors ([`swarm/dbn/features.py`](../swarm/dbn/features.py))

`extract_graph_features` constructs four purely observable feature tensors standardized strictly using training-split statistics (`FeatureNormalizer`, keeping one-hot `RelationType` columns `[0..3]` uncentered):

- **Vehicle Node Features $\mathbf{X}_V \in \mathbb{R}^{N_t \times 21}$ (`NODE_FEATURE_DIM = 21`)**: normalized remaining distance, static corridor length scale, normalized arc-length, speed/limit ratio, speed/$15\text{ m/s}$, $\hat{a}_i / 4$, $\sigma_{s,i}/5$, $\sigma_{v,i}/2$, $\min(\tau_{\text{age}}, 10)/5$, binned turn probabilities $(\pi_{\text{left}}, \pi_{\text{thru}}, \pi_{\text{right}})$, normalized turn entropy, lagged posterior delay $P(D_i^{t-1}=1 \mid b_{1:t-1})$, clipped free ETA, clipped wait time, corridor occupancy ratio, corridor tail blockage, normalized lane index, and belief-expected downstream occupancy & downstream tail blockage.
- **Corridor Node Features $\mathbf{X}_C \in \mathbb{R}^{N_C \times 12}$ (`CORRIDOR_FEATURE_DIM = 12`)**: length scale, speed limit scale, $\ell_{\text{eff}}/4$, open-lane fraction $\ell_{\text{eff}}/\ell_{\text{base}}$, effective storage capacity, occupancy ratio, tail blockage probability, expected upstream inflow over $H_p = 6.0\text{ s}$, normalized mean speed, live TLS green link fraction, lagged spillback prediction $q_{\text{spill}, c}^{t-1}$, and non-exit indicator.
- **Directed Candidate Pair Features $\mathbf{X}_E \in \mathbb{R}^{E_{\text{cand}} \times 18}$ (`EDGE_FEATURE_DIM = 18`)**: 4-D one-hot `RelationType`, signed & absolute $\Delta\widehat{\mathrm{ETA}} / 10$, signed path gap $/ 80\text{ m}$, relative speed $\Delta \hat{v} / 15$, belief-weighted $p_{\text{conflict}}$ and $p_{\text{merge}}$, ETA overlap score $\max(0, 1 - |\Delta\widehat{\mathrm{ETA}}|/3.5)$, same-corridor-and-lane indicator, combined position uncertainty $\sqrt{\Sigma_{j,00} + \Sigma_{i,00}}/7$, combined observation age, sum of turn entropies, previous raw edge probability $\omega_{j \to i}^{t-1}$, scaled temporal prior logit $\mathrm{logit}(p_{\text{prior}, e}^t)/5$, and edge persistence mask.
- **Corridor-to-Corridor Turn Features $\mathbf{X}_{CC} \in \mathbb{R}^{E_C \times 6}$ (`CORRIDOR_EDGE_FEATURE_DIM = 6`)**: turn-angle harmonics $(\sin\theta, \cos\theta)$ (`turn_sin`, `turn_cos`), through-movement indicator (`is_thru`), reverse backpressure-edge indicator (`is_backpressure_reverse`), live TLS green fraction (`tls_turn_green`), and downstream-to-upstream capacity ratio (`cap_ratio`).

### 4.3 `STGraphTransformerDBN` Architecture ([`swarm/dbn/transformer.py`](../swarm/dbn/transformer.py))

1. **Multi-Scale Physical Basis Expansion (`MultiScaleBasisEncoder`)**: Expands the 6 continuous geometric/kinematic pair columns (`cols [4, 5, 6, 7, 12, 13]` of $\mathbf{X}_E$: $\Delta\mathrm{ETA}, |\Delta\mathrm{ETA}|, \Delta s_{\text{path}}, \Delta v, \sigma_{ji}, \tau_{\text{age}, ji}$) onto $N_{\text{RBF}} = 16$ learnable Gaussian RBF kernels $\exp(-\frac{1}{2}((u - \mu_k)/\sigma_k)^2)$ plus $N_{\text{freq}} = 6$ log-spaced Fourier harmonics $[\sin(2^m \pi u), \cos(2^m \pi u)]$, concatenating $6 \times (16 + 12) = 168$ multi-scale basis features with standardized $\mathbf{Z}_E \in \mathbb{R}^{E_{\text{cand}} \times 18}$ (`186` total edge inputs projected to $d_{\text{edge}}$).
2. **Asynchronous Continuous-Decay Temporal Memory (`ContinuousDecayGRU`)**: Vehicle and corridor embeddings pass through a continuous-time decay gate before `GRUCell` fusion so tracks smoothly forget stale hidden states across sensor dropouts or arbitrary $\Delta t > 0$:

$$
\boldsymbol{\gamma}_i^t = \exp\!\Bigl(-\Delta t \cdot \mathrm{softplus}\bigl(\mathbf{W}_\tau \mathbf{x}_i^t + \mathbf{b}_\tau\bigr)\Bigr), \qquad \mathbf{h}_i^t = \mathrm{GRUCell}\!\bigl(\mathbf{x}_i^t,\; \boldsymbol{\gamma}_i^t \odot \mathbf{h}_i^{t-1}\bigr).
$$

3. **$L$-Layer 4-Stage Heterogeneous Message Passing (`STGraphTransformerBlock`)**: Each layer $l \in \{1, \dots, L\}$ executes:
   - *Stage 1 (Corridor Graph Attention)*: Edge-gated message passing over $\mathcal{G}_{\text{corr}} = (\mathcal{C}, \mathcal{E}_C)$ with SwiGLU FFN.
   - *Stage 2 (Macro-to-Micro Read-In)*: Injects hosting corridor context $\mathbf{h}_{c(i)}$ plus turn-probability-weighted outgoing corridor context $\sum_{m} \pi_{i,m} \mathbf{h}_{c_{\text{out}}(i,m)}$ into vehicle representation $\mathbf{h}_i$.
   - *Stage 3 (Edge-Augmented Sparse Multi-Head Vehicle Attention)*: Over candidate edges $(j \to i) \in \mathcal{E}_{\text{cand}}$ with $H$ heads ($d_h = d_{\text{model}} / H$), edge latents bias attention logits, value messages, and outer-product edge updates:

$$
\alpha_{j \to i}^{(h)} = \mathrm{softmax}_{j \in \mathcal{N}_{\text{in}}(i)}\!\left(\frac{\mathbf{q}_i^{(h)} \cdot \mathbf{k}_j^{(h)}}{\sqrt{d_h}} + b_{j \to i}^{(h)}\right), \qquad \mathbf{m}_i^{(h)} = \sum_{j \in \mathcal{N}_{\text{in}}(i)} \alpha_{j \to i}^{(h)} \bigl(\mathbf{v}_j^{(h)} + \mathbf{u}_{j \to i}^{(h)}\bigr),
$$

   followed by residual LayerNorm and SwiGLU FFN ($\lfloor d_{\text{model}} \cdot \text{ffn\_mult} \rfloor$).
   - *Stage 4 (Micro-to-Macro Scatter-Mean Read-Out)*: Pools updated vehicle states back into their hosting corridors.

### 4.4 Two-Slice Causal DBN, Generalized Noisy-OR CPDs, & Division-Free Sum-Product LBP ([`swarm/dbn/cpd.py`](../swarm/dbn/cpd.py), [`swarm/dbn/inference.py`](../swarm/dbn/inference.py))

1. **Topological Precedence Anchor & Bounded Neural Residual**: Ensures global DAG acyclicity via a physically grounded anchor $r_{\text{topo}}(i, b_t) = -\widehat{\mathrm{ETA}}_i^t + 15.0\, b_{\text{tail}}(i)$ plus bounded learned residual:

$$
r_i^t = r_{\text{topo}}(i, b_t) + 3.0 \tanh\!\left(\frac{\Delta r_i^t}{3.0}\right).
$$

2. **First-Order Markov Temporal Edge Prior (`temporal_edge_prior`)**: Stabilizes structure across consecutive $0.5\text{ s}$ ticks ($p_{\text{stay}} = 0.80$, $p_{\text{base}} = 0.10$; ablated to $p_{\text{stay}} = 0$ in `no_temporal_prior`):

$$
p_{\text{prior}, e}^t = \mathbf{1}_{\text{pers}, e}^t \bigl[(1 - p_{\text{stay}}) p_{\text{base}} + p_{\text{stay}} \omega_e^{t-1}\bigr] + (1 - \mathbf{1}_{\text{pers}, e}^t) p_{\text{base}}, \qquad \omega_{\text{raw}, e}^t = \sigma\!\left(\frac{\mathrm{logit}(p_{\text{prior}, e}^t) + \Delta \ell_{\text{edge}, e}^t}{T_{\text{edge}}}\right).
$$

3. **Corridor Spillback Head (`CorridorSpillbackCPD`) & Generalized Causal Noisy-OR Node Survival**: Corridor spillback logits combine a monotonic structural flux prior (`occ_ratio`, `tail_blockage_prob`, `expected_inflow`, `prev_spillback`) with learned $\Delta \ell_{\text{spill}, c}^t$, scaled by $1 / T_{\text{link}}$. Each vehicle's non-parent survival probability $z_{i,0}^t \in [10^{-6}, 1 - 10^{-6}]$ combines base leak $q_{i,0}^t$, temporal self-persistence $q_{i,\text{self}}^t P(D_i^{t-1}=1)$, and turn-weighted downstream spillback $w_{i,\text{spill}}^t \bar{q}_{\text{down}, i}^t$ (scaled by $1 / T_{\text{delay}}$):

$$
z_{i,0}^t = (1 - q_{i,0}^t)\bigl(1 - q_{i,\text{self}}^t P(D_i^{t-1}=1)\bigr)\bigl(1 - w_{i,\text{spill}}^t \bar{q}_{\text{down}, i}^t\bigr).
$$

   In the `static_cpd` ablation, neural CPD parameters are replaced with fixed physical constants ($q_0 = 0.05$, $q_{\text{self}} = 0.45$, $w_{\text{spill}} = 0.55$) and analytic edge $(\kappa_e, \gamma_e)$.
4. **Precedence DAG Gating & 62-Bit Radix Top-$K_{\max}$ Parent Pruning (`gate_and_prune_edges`)**: Candidate edge $(j \to i)$ is orientation-valid iff $(r_j^t > r_i^t) \lor (r_j^t = r_i^t \land j < i)$. Valid incoming parents with $\omega_e^t \ge \omega_{\min} = 0.05$ are sorted per destination node via a single vectorized 62-bit integer radix key (`dst_idx << 32 | ~uint32(omega)`) to retain at most $K_{\max} = 6$ parents (`require_dag` verifies acyclicity via Kahn's algorithm at runtime).
5. **Division-Free Prefix-Suffix Multiplicative Sum-Product LBP (`multiplicative_sum_product_lbp`)**: Each active parent $(j \to i)$ exerts baseline conflict inhibition $\kappa_{j \to i} \in [0, 1]$ even when $D_j^t = 0$ and cascade amplification $\gamma_{j \to i} \in [0, 1]$ when $D_j^t = 1$, yielding survival factors $\phi_{j \to i}(0) = 1 - \omega_{j \to i}\kappa_{j \to i}$ and $\phi_{j \to i}(1) = 1 - \omega_{j \to i}\bigl(\kappa_{j \to i} + (1 - \kappa_{j \to i})\gamma_{j \to i}\bigr)$. Incorporating soft current-tick kinematic speed evidence $L_i^t(1) = 0.5 + 0.42 e^{-\tau_{\text{age}, i}/3} \bigl(2\sigma((0.45 v_{\max, c} - \hat{v}_i)/1.2) - 1\bigr)$ and $L_i^t(0) = 1 - L_i^t(1)$, 3 damped ($\alpha_{\text{lbp}} = 0.50$) message-passing sweeps compute exact cavity products $S_{i \setminus p}$ via **segmented prefix-suffix products** (`_segmented_exclusive_products`) with **zero division by $(1 - \lambda)$** (eliminating `0/0` NaN singularities under saturated inhibition):

$$
P_{\text{pred}}(D_i^t = 1) = 1 - z_{i,0}^t \prod_{j \in \mathrm{Pa}(i)} m_{j \to i}, \qquad P_{\text{post}}(D_i^t = 1 \mid b_{1:t}) = \frac{L_i^t(1)\bigl(1 - z_{i,0}^t \prod_{j} m_{j \to i}\bigr)}{L_i^t(0) z_{i,0}^t \prod_{j} m_{j \to i} + L_i^t(1)\bigl(1 - z_{i,0}^t \prod_{j} m_{j \to i}\bigr)}.
$$

   Downstream 2-hop congestion impact is summarized by the causal cascade score $\psi_i^t = \sum_{k \in \mathrm{Ch}(i)} w_{i \to k}(1 + \sum_{m \in \mathrm{Ch}(k)} w_{k \to m})$ with $w_{j \to i} = \omega_{j \to i}(\kappa_{j \to i} + \gamma_{j \to i})$.

### 4.5 Offline Supervision Labels, Unrolled TBPTT Loss, & L-BFGS-B Calibration

- **Offline Future-Window Causal Labels ([`swarm/pipelines/labels.py`](../swarm/pipelines/labels.py))**: Computed strictly offline over $[t, t + H_p]$ ($H_p = 6.0\text{ s}$) from recorded non-neural rollout shards:
  - Continuous future delay $\tau_{\text{delay}, i}^t = \min(H_p, \max(\Delta\text{timeLoss}_i, \Delta t_{\text{eff}} - \Delta d_i / v_{\max, c}))$ and binary delay onset $y_{\text{delay}, i}^t = \mathbf{1}[\tau_{\text{delay}, i}^t \ge 1.5\text{ s}]$.
  - Corridor spillback $y_{\text{spill}, c}^t = 1$ iff any vehicle halts in the upstream tail ($s \le 22.0\text{ m}, v < 1.5\text{ m/s}$) or corridor occupancy reaches $\ge 85\%$ of $C_{\text{eff}}(c)$ at mean speed $< 2.5\text{ m/s}$ within $[t, t + H_p]$.
  - Relation-specific directed causal edge labels $y_{\text{edge}, j \to i}^t \in \{0, 1\}$ and asymmetric precedence pairs $\mathcal{R}_t = \{(j, i) : y_{j \to i}^t = 1 \land y_{i \to j}^t = 0\}$.
- **8-Term Multi-Task Causal Loss ([`swarm/pipelines/trainer.py`](../swarm/pipelines/trainer.py))**: Contiguous episode windows ($T_{\text{burn}}$ detached burn-in ticks + $T_{\text{seq}}$ supervised ticks, batched on GPU as Disjoint-Union Super-Graphs) optimize AdamW (`lr = 3e-4` for `sota_local`, `2.5e-4` for `sota_cloud_xl`, `weight_decay = 0.01`, cosine schedule with `10%` warmup, `grad_clip = 1.0`, `bf16` autocast with FP32 loss reduction):

$$
\mathcal{L} = \mathcal{L}_{\text{BCE}}^{\text{pred}} + 0.5\,\mathcal{L}_{\text{BCE}}^{\text{post}} + 1.2\,\mathcal{L}_{\text{focal}}^{\text{edge}}(\gamma{=}2) + 0.4\,\mathcal{L}_{\text{rank}} + 0.5\,\mathcal{L}_{\text{Huber}}^{\tau}(\delta{=}2) + 1.0\,\mathcal{L}_{\text{BCE}}^{\text{spill}} + 0.15\,\mathcal{L}_{\text{smooth}} + 0.02\,\|\boldsymbol{\omega}_{\text{raw}}\|_1.
$$

- **Post-Hoc Temperature Scaling ([`swarm/dbn/calibration.py`](../swarm/dbn/calibration.py))**: Minimizes unweighted Bernoulli negative log-likelihood on `VAL_SEEDS` (`2000..2009`) in `model.eval()` hard-DAG mode via bounded L-BFGS-B (`bounds = [0.15, 10.0]`, initialized across 5 log-temperatures) separately for `edge` ($T_{\text{edge}}$), `delay_pred` ($T_{\text{delay}}$), and `spillback` ($T_{\text{link}}$).

## 5. Factored Multi-Intersection Swarm Coordinator (`swarm/control/`)

### 5.1 5-Iteration Damped Max-Sum Coordination ([`swarm/control/maxsum.py`](../swarm/control/maxsum.py))

Over the sparse DAG $\mathcal{G}_t = (\mathcal{V}_t, \mathcal{E}_t)$ and discrete longitudinal mode set $\mathcal{U} = \{\texttt{GO\_WAVE}~(v_{\max}), \texttt{CRUISE}~(\max(v, 0.85v_{\max})), \texttt{ECO\_GLIDE}~(0.52v_{\max}), \texttt{YIELD}~(0)\}$, each vehicle's crossing window $[t_{\text{in}}(u), t_{\text{out}}(u)]$ uses strictly physical intersection clearance $(14.0\text{ m} + L_{\text{veh}, i} + s_0) / v(u) + 1.645\,\sigma_{\text{ETA}, i}$ (95% one-sided uncertainty, zero artificial slot bloat). Unary utilities incorporate wait-time & 2-hop cascade priority $M_i = 1 + 0.08\min(60, w_i) + 0.65\psi_i^t$ (`cascade_weight = 0.65`) and penalize crossing when belief-expected outgoing spillback $\bar{q}_{\text{out}}(i) = \sum_{m} \pi_{i,m} q_{\text{spill}}(c_{\text{out}}(i,m)) > \theta_{\text{spill}} = 0.55$. Pairwise factors encode:
- **`SAME_JUNCTION_CONFLICT`**: Temporal slot overlap penalty $-c_{\text{conf}} \frac{\omega_e p_{\text{conf,eff}}}{\sqrt{\deg_{\text{conf}}(i)}}(0.6 + \text{overlap}/\min\text{dur})$ (`conflict_penalty = 8.0`, `conflict_risk_threshold = 0.22`).
- **`SAME_CORRIDOR` / `UPSTREAM_FEEDER`**: Green-wave speed harmony $+1.2\,\omega_e \exp(-|v_j(u_j) - v_i(u_i)| / 3.5)$ (`platoon_harmony_weight = 1.2`) and anti-rear-end penalty when $u_j = \texttt{YIELD}$.
- **`DOWNSTREAM_SPILLBACK`**: Upstream backpressure penalty gated by downstream tail spillback and $\omega_e(\kappa_e + (1 - \kappa_e)\gamma_e P_{\text{post}}(D_j^t=1))$ (`spillback_penalty = 6.0`).

Five synchronous rounds of mean-centered Damped Max-Sum ($\lambda = 0.50$) yield node utilities $Q_i(u)$, best mode $u_i^* = \arg\max_u Q_i(u)$, and net crossing margin $\Delta Q_i = \max(Q_{\text{GO}}, Q_{\text{CRUISE}}) - \max(Q_{\text{GLIDE}}, Q_{\text{YIELD}})$.

### 5.2 Conflict-Free Priority-DAG TLS & Slot Scheduler ([`swarm/control/scheduler.py`](../swarm/control/scheduler.py))

`PriorityDAGScheduler` decodes each junction $J \in \mathcal{J}$ independently while preserving same-lane physical FIFO order via a min-heap topological sort:
1. **Max-Pressure Coalition Ranking**: Movement pressure aggregates slow-queue bonus, wait time, and DBN `cascade_score` $\psi_i^t$, scaled by multi-lane service capacity $\mu_m = \min(2.0, 0.65 + 0.35|\mathcal{L}_m|)$, a $> 24\text{ s}$ red anti-starvation floor, a $< 26\text{ s}$ active platoon green-wave continuation bonus, and compatible non-foe coalition pressure.
2. **Spillback & Storage-Capacity Backpressure Gate**: Any movement whose outgoing non-exit corridor exceeds $\theta_{\text{spill}} = 0.55$ or has zero remaining storage slots ($C_{\text{eff}}(c_{\text{out}}) - N_{c_{\text{out}}} \le 0$) is placed in `must_hold_stopline`—holding the blocked movement upstream while allowing orthogonal unblocked cross-streets at the same intersection to flow freely.
3. **Guaranteed Conflict-Free TLS Phase Synthesis**: Selected TLS link indices are checked against `JunctionSpec.tls_link_foe_matrix` (`are_tls_links_compatible` + `verify_conflict_free_greens`), completed with compatible non-conflicting dual-through phases (`_fill_compatible_greens`), held for at least `tls_min_green_hold_s = 6.0 s`, and guarded in SUMO by an automatic `tls_yellow_clearance_s = 3.0 s` yellow (`y`) transition before any foe link opens.

### 5.3 Eco-Glide Pacing, Public DBN Routing, Budgeted VoI V2X, & Observable Safety Filter

- **Eco-Glide Speed Profiler ([`swarm/control/ecoglide.py`](../swarm/control/ecoglide.py))**: Maps `ScheduleResult` slot start times $t_{\text{slot}, i}$ and uncertainty-buffered stop distances $d_{\text{stop}, i} = \max(0, L_c - \hat{s}_i - 0.6 - 1.5\sqrt{\Sigma_{i,00}})$ into smooth non-stopping arrival speeds $v_{\text{des}, i} \in [v_{\min,\text{glide}}, v_{\max, c}]$ ($v_{\min,\text{glide}} = 2.2\text{ m/s}$) or comfortable braking envelopes $\sqrt{2 b_{\text{comf}} d_{\text{stop}, i}}$ ($b_{\text{comf}} = 2.2\text{ m/s}^2$).
- **Firewall-Safe Public Route Broadcaster ([`swarm/control/routing.py`](../swarm/control/routing.py))**: Every $\Delta t_{\text{reroute}} = 6.0\text{ s}$ (`reroute_interval_s = 6.0`), broadcasts public corridor travel-time estimates $\hat{c}_c^{\text{DBN}}(t) = t_{\text{free}, c} + (0.45\bar{\tau}_{\text{DBN}, c} + 0.55 N_c/\ell_{\text{eff}}) + 4.0(\text{occ}_c + \text{inflow}_c/C_{\text{eff}}) + 18.0\,q_{\text{spill}, c} + \text{lane\_loss} + \text{minor\_road}$ (`reroute_flux_weight = 8.0` with $0.50$ scaling, `reroute_spill_weight = 18.0`) partitioned proportionally across constituent edges. Vehicles reroute onboard via `sumolib` shortest path only if travel-time savings exceed `reroute_hysteresis_s = 15.0 s`.
- **Value-of-Information V2X Polling ([`swarm/control/v2x.py`](../swarm/control/v2x.py))**: Ranks cooldown-eligible active vehicles under the shared budget $B_{\text{comm}} = 8$ (`6` in `grid3x3_noisy_dropout`) by:

$$
\mathrm{VoI}_i = \frac{\bigl(H(\boldsymbol{\pi}_i) + 0.25\sqrt{\Sigma_{i,00}} + 0.30\,\tau_{\text{age}, i} + 0.05\bigr)(1 + \psi_i^t)}{1 + 0.20\,\widehat{\mathrm{ETA}}_i^t}.
$$

- **Observable Longitudinal Safety Filter & Cooperative LC2013 Release ([`swarm/control/safety.py`](../swarm/control/safety.py))**: Bounds desired speeds using an uncertainty-inflated observable IDM envelope ($s^* = s_0 + u_{\text{margin}} + \max(0, 0.85 v \tau_{\text{hw}} + v \Delta v / (2\sqrt{a_{\text{comf}} b_{\text{comf}}}))$, $u_{\text{margin}} = \min(1, v/4) \cdot 1.5\sqrt{\Sigma_{i,00} + \Sigma_{\text{lead},00}}$, $s_0 = 2.0\text{ m}$, $\tau_{\text{hw}} = 1.3\text{ s}$), stop-line hold cap, physical acceleration bounds $[-b_{\max}, a_{\text{comf}}] = [-6.5, +2.0]\text{ m/s}^2$, and zero-speed anti-creep deadzone ($v < 0.15\text{ m/s} \implies 0$). `select_actuated_target_speeds` emits active `setSpeed` overrides only when longitudinal pocket holding, unsignalized AIM pacing, or emergency braking is active, issuing `-1.0` otherwise so SUMO `LC2013` turn-pocket lane-changing operates unimpeded.

## 6. Pre-Registered Experimental & Non-Parametric Statistical Protocol

### 6.1 Disjoint Seed Partitions & SUMO Physics Configuration

All random number generators (OD route sampling, sensor/V2X noise, model initialization) are locked to disjoint pre-registered integer seed ranges in [`swarm/config.py`](../swarm/config.py):
- **`TRAIN_SEEDS = 1000..1039`** (`40` seeds — `grid3x3_*` non-neural rollouts only),
- **`VAL_SEEDS = 2000..2009`** (`10` seeds — `grid3x3_*` checkpoint selection & Boundary Lock B L-BFGS-B calibration only),
- **`TEST_SEEDS = 3000..3014`** (`15` seeds — held-out closed-loop & predictive evaluation; passing any train/val seed to `evaluate` with `require_test_seeds = True` raises `ConfigValidationError`).

Every SUMO episode runs with `--collision.check-junctions true`, `--time-to-teleport -1` (zero silent gridlock teleports), and `speedMode = 31` (full physical deceleration/collision checks enabled).

### 6.2 Exact Cohort Conservation Accounting ([`swarm/env/sumo_adapter.py`](../swarm/env/sumo_adapter.py))

Each episode comprises a `60 s` warmup, a `240 s` evaluation cohort window $[60\text{ s}, 300\text{ s})$, and a `180–240 s` drain window. Metrics are computed strictly over the identical scheduled cohort $\mathcal{K}_{\text{cohort}} = \{i : 60 \le t_{\text{sched}, i} < 300\}$, enforcing exact conservation $N_{\text{completed}} + N_{\text{unfinished}} + N_{\text{undeparted}} = |\mathcal{K}_{\text{cohort}}|$:
- **Departed vehicles (completed or unfinished at episode end)**: $d_i = \max(0, \text{departDelay}_i) + \max(0, \text{timeLoss}_i)$.
- **Undeparted vehicles (held outside network by entry spillback)**: $d_i = \max(0, \text{departDelay}_i, T_{\text{end}} - t_{\text{sched}, i})$.
This eliminates survivorship bias when baseline controllers gridlock and fail to discharge $< 50\%$ of the cohort.

### 6.3 Paired Bootstrap CIs & Step-Down Holm-Bonferroni Wilcoxon Tests ([`swarm/pipelines/statistics.py`](../swarm/pipelines/statistics.py))

For each scenario and metric $m$, let $\Delta_s = m_{\text{ref}}(s) - m_{\text{base}}(s)$ denote the paired seed difference across $s \in \{3000, \dots, 3014\}$ ($n = 15$):
1. **95% Confidence Intervals**: Computed via `10,000` paired percentile bootstrap resamples (`rng_seed = 202611`) without Gaussian small-sample assumptions.
2. **Hypothesis Testing**: Exact two-sided Wilcoxon signed-rank $p$-values (`scipy.stats.wilcoxon`, `zero_method="wilcox"`, `mode="auto"`), adjusted across all $M$ baseline comparisons within each `(scenario, metric)` family via step-down **Holm-Bonferroni** correction:

$$
p_{\text{holm},(k)} = \max_{j \le k} \min\!\bigl(1,\; (M - j + 1)\, p_{\text{raw},(j)}\bigr), \qquad k = 1, \dots, M,
$$

accompanied by directional seed Win / Tie / Loss (`W/T/L`, tie tolerance $10^{-9}$) counts.
